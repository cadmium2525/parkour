# 天空パルクール SKY STAIRS RUSH

山の大階段を駆け降りるパルクール・タイムアタック。
障害物を飛び越え、アイテムを集め、コンボを繋いで**ド派手に**ゴールを目指すブラウザゲームです。

- インストール不要・PC / スマホ両対応（縦画面OK）
- 画像・音声ファイルは一切なし（テクスチャも効果音もBGMもすべてプログラム生成）
- ビルド不要の静的サイト → **GitHub Pages で無料公開（開発・運用コスト 0円）**

## あそびかた

| 操作 | PC | スマホ |
| --- | --- | --- |
| レーン移動 | ← → / A D | 左右スワイプ |
| ジャンプ（空中でもう一回で**宙返り**） | ↑ / W / Space | タップ / 上スワイプ |
| スライディング（空中なら急降下） | ↓ / S | 下スワイプ |
| ポーズ | P / Esc | ❚❚ ボタン |
| 視点切替（三人称 / 一人称） | C | 設定画面 |

### ルール
- スタートからゴールまでの**タイム**と**スコア**を競います（ゴール時にタイムボーナス加算 → TOTAL でランク判定 C〜SSS）
- 障害物にぶつかると減速＆コンボ消滅。ゲームオーバーはないので最後まで走り切れます

### コース上のもの
- **ハードル / 青テープの台**：ジャンプで越える。ギリギリで跳ぶと **PERFECT!**（台には飛び乗って上を走れる）
- **黄黒のバー**：スライディングでくぐる
- **黒い壁**：越えられないのでレーン移動で回避（すれすれで避けると「ギリギリ!!」ボーナス）
- **ジャンプ台**：大ジャンプ中にジャンプ連打で多段宙返り。着地前に回りきらないと失敗
- **銀の滑り台**：超加速＆コンボを稼げる
- **ブーストパッド**：一気に加速
- アイテム：コイン、◆ジェム（大量得点）、⏱時計（タイム -1秒）、★スター（フィーバーゲージ大幅UP）

### コンボ & フィーバー
- コイン・障害物クリア・トリックでコンボが繋がり、10コンボごとに倍率UP（最大 x5.0）
- 10 / 25 / 50 / 75 / 100 …コンボで演出（「えぐい!!!!」「神!!!!!」など）
- コンボが時間切れで途切れると **COMBO FINISH ボーナス**、ぶつかると全部消滅
- ゲージMAXで **FEVER**：無敵・スコア2倍・障害物を粉砕・コイン吸い寄せ・空が虹色に

### その他
- 自己ベストの走りを**ゴースト**として再生、チェックポイントで区間タイム差を表示
- 「今日のコース」は日付ごとに自動生成される日替わりコース
- 記録はブラウザ（localStorage）に保存。リザルトから 𝕏 でシェアできます
- 設定の「エフェクト：控えめ」で画面の揺れ・フラッシュを抑えられます

## GitHub Pages で公開する（無料）

1. このリポジトリの **Settings → Pages** を開く
2. **Build and deployment** の Source を **Deploy from a branch** にする
3. Branch で公開したいブランチ（例: `main`）と `/ (root)` を選んで **Save**
4. 1〜2分後に `https://<ユーザー名>.github.io/parkour/` で遊べます

※ 公開リポジトリなら GitHub Pages は無料です。ビルド手順はありません（ファイルを置くだけ）。

## ローカルで動かす

ES Modules を使っているので、ファイルを直接開くのではなく簡易サーバー経由で開いてください。

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 構成

```
index.html          画面・HUD
css/style.css       UI と演出（ポップアップ / バナー / ランク等）
js/main.js          ゲーム本体（物理・スコア・コンボ・フィーバー・カメラ・画面遷移）
js/course.js        シード固定のコース生成（階段 / 踊り場 / 障害物 / アイテム配置）
js/world.js         3Dワールド（大階段・手すり・カルスト峰・雲・観客・障害物）
js/player.js        ローポリのランナーとアニメーション
js/fx.js            パーティクル・破片・衝撃波リング・虹トレイル・集中線
js/audio.js         WebAudio による効果音とBGM（150BPM）
js/hud.js / input.js / textures.js / util.js
lib/three.module.min.js   three.js r170（MIT License）
```
